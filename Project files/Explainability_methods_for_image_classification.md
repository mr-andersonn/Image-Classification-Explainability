# Explainability methods for image classification

In a convolutional neural network with millions of parameters, how can we explain exactly what made the network come to its conclusion? Different explanation methods have been proposed to answer this question in form of a heatmap, a visual representation of which pixels in an image were important to the decision. Implement some of these methods from scratch, and analyse their strengths and weaknesses in providing an understandable (to a human!) explanation of an image classifier's outputs.

Suggested use: In addition to comparing results and expectation on a set of test images, deploy a website where users can upload pictures and get both a classification result, and a explanation in form of a heatmap.
